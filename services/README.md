# Services
The executable services are the authenticated API, production outbox workers, provider integration gateway, PostgreSQL migrator, and client integration broker. The client broker is the isolated HTTPS boundary for official WeChat code exchange, enterprise-IdP sessions, and KMS-encrypted resumable S3 uploads. Media, notifications, billing, fulfillment, integrations and analytics share hardened routing and evidence primitives where appropriate; B00/B01 ownership and trust boundaries determine deployment splits rather than capability names alone.

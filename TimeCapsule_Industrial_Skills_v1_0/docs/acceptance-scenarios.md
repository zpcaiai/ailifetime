# 验收场景与故障注入目录

A01 微信登录登录态过期 → 刷新或重新认证，不遗失草稿。
A02 同时提交同一 render key 100 次 → 唯一逻辑作业；可返回已有作业状态。
A03 AI provider 429、5xx、超时、成功但网络断连 → 退避/查询/幂等恢复；不无限重试。
A04 PG 提交成功但 outbox 投递失败 → 由 outbox scanner 最终投递一次逻辑事件。
A05 S3 上传成功数据库失败 → orphan scanner 删除或补录；不得泄漏。
A06 200 字中文、Emoji、RTL 混排、姓名中的不常见字、缺失字体 → 无静默丢字且可调整排版。
A07 生成图片返回前撤回同意 → 不发布、不导出，进入删除/隔离路径。
A08 支付回调重复 100 次、乱序回调、退款先后 → 权益发放/回收一次，对账一致。
A09 下载图片经过格式转码 → 显式标识仍在，隐式标识依据每种导出格式验证。
A10 用户 A 请求用户 B 的照片/分享/订单 → 403；admin 也必须有审计和最小权限。
A11 小程序分享被撤销 → 旧链接不能访问。
A12 模板版本升级后旧作品重渲染 → 绑定原 manifest 版本，结果可复现或明确说明素材/模型不可重现。
A13 预算达到上限 → 在收费前阻断新任务，已收款任务进入可追踪的退费/补偿流程。
A14 上传超大尺寸/文件伪装/异常 EXIF → 安全拒绝。
A15 禁止绕过 AI 合成标签导出，包括截图式 API 或历史转码路径。

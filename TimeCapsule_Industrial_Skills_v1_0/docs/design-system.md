# 模板设计系统

- 输出尺寸初期：1080×1440（3:4），1080×1920（9:16），1080×1080（1:1）；更多尺寸经 renderer 契约加。
- 采用 normalized 0..1 的安全区域和元素坐标；文字保留安全边距，不与人物面部相撞。
- 所有字体需明确商业授权和 CJK fallback；保存所用字体版本与字形覆盖测试。
- 视频与印刷输出独立管线，不把静态卡片渲染器直接视为视频服务。
- QR 数据必须由业务 API 生成且白名单校验；禁止渲染不受信任的任意跳转 URL。
- 模板需支持视觉低配版与付费高清版本，布局保持一致，仅受授权影响改变清晰度/内容。
- 支持大字、色弱对比度、屏幕阅读器 label、系统字体缩放及安全区。
- 每个模板有 cover 缩略图、示例、必填字段、可选字段、图片槽位、声明提示和版本。

# 财务单元经济学与埋点

成本 / 成功作品 = (模型调用含重试 + 图像存储与下行 + 渲染CPU + 审核 + 支付手续费 + 客服/退款可分摊) / 成功交付件数。

指标：template_view→start→upload→render_success→preview→checkout→payment_success→export→share→repeat；分模板、渠道、年龄群组（仅合法汇总）、价格包做 cohort；不记录敏感图片内容。

定价测试候选：免费、¥2.9-9.9 单次、¥19.9-59 纪念套装。必须 A/B 验证付费率、退款率、模型成本、二次消费率、分享带来新用户率；不得把候选价当财务事实。

推荐限额：每天每用户生成次数上限、每个 job 最大重试次数、全局日支出上限、供应商超支熔断；具体值通过压测和预算设定。

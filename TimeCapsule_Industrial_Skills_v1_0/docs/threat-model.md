# 威胁模型 STRIDE / Abuse Cases

| 威胁 | 防护 | 验证 |
|---|---|---|
| 跨用户访问原图/作品 | user-scoped ACL, short-lived signed URL, private object bucket | 两用户越权访问 403 |
| 上传恶意文件、EXIF 地理位置 | MIME 内容识别、解码隔离、像素/字节上限、清理 EXIF | 伪造 MIME / polyglot 测试 |
| 提示词注入、恶意生成 | 受控 prompt、内容审核输入输出、回退人工复核 | 红队样本与申诉流程 |
| 盗用真人肖像、儿童影像 | 权利确认、同意留痕、年龄敏感策略、举报/删除 | 未授权任务被拒 |
| 重复通知发放权益 | Webhook验签、事件唯一键、事务约束 | 重播 100 次只发一次 |
| 恶意刷图费用爆炸 | 并发/每日额度、用户配额、provider budget cap | 压测、账单阈值模拟 |
| 伪造优惠金额、支付状态 | 服务端定价快照、签名校验、订单状态机 | 改价攻击失败 |
| 未标识的合成图片外流 | 水印与元数据标识，导出后检测 | 图像保留显式/隐式标识 |
| 内部员工批量浏览照片 | RBAC/ABAC、break-glass、全量审计 | 最小权限及告警 |
| 删除后残留副本 | tombstone、队列补偿、对象版本和备份保留政策 | 删除证明/周期性对账 |

注意：隐式标识具体技术要求需依据现行强制国标 GB 45438-2025（实施与适用须复核），这里的元数据字段只是接口草案，不宣称已满足国标。

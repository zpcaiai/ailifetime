## 每片的验收契约
输入：相关模板、字段 schema、权限上下文、风险假设。输出：代码、迁移、API diff、自动化测试、手动 UX 检查、成本数据、证据 manifest。未过验收门不得开始依赖它的切片。

## Release Gates
- R0：E0/E1 全过、Schema 可解析、关键状态覆盖。
- R1：E2 契约、权限、幂等、模拟供应商故障全过。
- R2：E3 真实 PostgreSQL/对象存储/队列恢复测试及安全评估。
- R3：E4 真实 AI 提供商、小程序真机、可用支付测试模式、合规签核。
- R4：E5 1%→10%→50%→100% 灰度，关键指标不退化，具备立即回滚。

# 中国大陆正式上线前人工合规核对

- [ ] 营业主体、平台类目、微信小程序认证、ICP备案或许可证及其他资质按实际服务类别确认。
- [ ] 核实使用的 AI 服务提供者是否满足适用的备案/登记义务；评估自身服务是否需履行备案或登记，不能用上游备案自动替代所有自身义务。
- [ ] 《生成式人工智能服务管理暂行办法》的适用及内容治理流程已评估。
- [ ] 《人工智能生成合成内容标识办法》及 GB 45438-2025 的显式和隐式标识要求经测试验证。
- [ ] 个人信息/肖像处理合法性基础、独立同意或监护人同意场景、撤回、删除、投诉与数据最小化完整。
- [ ] 存储地域、第三方数据流向、跨境传输与供应商数据使用政策已完成评估。
- [ ] 微信支付开通资格、交易/退款/对账、虚拟商品规则、用户协议与价格展示经核实。
- [ ] 已核实商业化模板字体、图片、人物肖像、插画、音乐、素材的授权范围。
- [ ] 禁止伪造官方身份、学历/职业资质；历史影像及未来年龄推演明确标注模拟。
- [ ] 发布、搜索、分享传播形式及平台审核已完成真机和商户联调。

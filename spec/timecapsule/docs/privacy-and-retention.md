# 数据治理 / 生命周期

数据分类：用户标识（PII）、联系方式（PII）、人像原图（敏感度高）、儿童照片（高敏感处理）、生成照片、用户文字、支付流水、合规审计。

上传前：展示处理目的、用途、第三方供应商、保存时间与分享范围，取得适用授权；监护人代儿童处理需适用的监护人许可流程。

默认：私有作品；分享为独立、可撤销的受限 token，不以 user_id 作为公开 URL；原图默认不供公开下载。

撤回/删除：将资产标记不可访问→阻止新作业→撤销签名分享→排队删除对象及派生图→处理供应商侧删除可得的请求→保留必要交易/合规凭据按法律要求隔离→发可审计回执。

保留策略：必须在正式上线前基于法律与商业需求选择明确期限；不得把示例配置当成合法默认。删除与备份生命周期应显式披露。

训练：默认禁用使用用户上传的人像作为模型训练素材；要额外使用必须独立告知并取得适用授权。

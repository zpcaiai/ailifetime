# 渠道验收矩阵

| 渠道/表面 | 必需验收 |
|---|---|
| 营销官网/CMS | SEO 与性能；同意前最小追踪；发布审批；旧 URL；品牌/信任/状态中心；不得使用预测性营销宣称 |
| 消费者 Web | 匿名到账号升级；上传/恢复；0—100 岁生成；家庭/未来自我；支付/退款；分享撤销；删除 |
| iOS/Android | 安全存储；断点上传；IAP 签名校验/恢复；深链/推送；离线/升级；隐私标签；商店灰度/回滚 |
| 微信小程序 | 微信登录；隐私授权；上传/生成；微信支付；分享二次鉴权；客服/服务通知；审核与版本回退 |
| 影楼/门店/自助终端 | 门店/店员隔离；现场逐人授权；离店扫码取件；离线恢复；品牌模板不遮挡 AI 标识；订单/分账/退款可对账；门店不超期留原图 |
| 纪念礼品/电商 | 礼品购买者与照片主体授权分离；收件人/地址最小化；数字与实体 SKU 同订单；打样、生产、物流、破损补发、退货和供应商删除闭环 |
| 保险/养老教育 | 清晰声明教育/反思用途；不得向承保、定价、理赔、资格或销售评分发送人脸/交互信号；线索交接需独立同意 |
| 伙伴门户 | 组织/租户/品牌/合同/人员/SSO；产品/用量/账单；审计；停用时撤销所有凭据和访问 |
| 开发者平台 | 文档/沙箱；最小 scopes；密钥轮换；SDK 兼容；Webhook 签名/重放/死信；合成数据；认证与弃用 SLA |
| 客服 | 全渠道工单；机器人清晰披露；人工接管；客户 360 最小化；退款/补发/删除等受控动作；全程审计 |
| 财务/税务 | 支付/银行/伙伴/供应商对账；复式分录；发票/电子发票；收入/递延/礼品负债；拒付；付款；月结双人复核 |
| 数据/运营 | 事件 schema；PII 治理；漏斗/归因/LTV；账本对照；实验护栏；模型漂移；异常告警和数据质量事件 |

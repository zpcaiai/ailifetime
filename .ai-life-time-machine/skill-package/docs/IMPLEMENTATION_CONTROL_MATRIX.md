# Implementation Control Matrix

| 控制面 | 主责 Batch | 强制输出 | 发布阻断条件 |
|---|---|---|---|
| 产品范围/体验 | B51–B56 | Profile、研究、IA、设计系统、无障碍、视觉门 | Profile 漂移；必要告知不可访问 |
| 身份/租户/权限 | B03、B31、B104 | 权限矩阵、跨租户负测、审计、API scopes | 任一跨租户读写成功 |
| 肖像授权/数据权利 | B04、B19、B21、B44 | 逐人用途化同意、监护、撤回/导出/删除回执 | 同意未知仍可生成、分享或供应商处理 |
| 媒体生命周期 | B05、B17、B46 | 加密、保留期、来源、AI 标识、下游删除证明 | 原图/供应商副本不可删除；标识可付费移除 |
| AI 生成质量 | B12–B18、B118 | Provider 契约、基准、身份/年龄/连续性指标、漂移 | 失败伪装成功；身份漂移；预算无限重试 |
| 家庭/未来自我 | B19–B24 | 家庭权限、儿童安全、拟人化披露、危机退出 | 依赖诱导；儿童内容越界；授权成员被绕过 |
| 商品/权益/订单 | B25–B29、B66、B71 | 价格快照、权益状态机、数字/实物交付 | 客户端改价；跨端权益不一致；重复交付 |
| 支付/账本/财税 | B26、B34、B87–B94 | 幂等支付、复式分录、对账、税票、收入、月结 | 支付成功但账不平；重复退款/分账；期间不可复核 |
| 实物供应链 | B95–B102 | 规格、校样、PO、产能、物流、退换、索赔、供应商删除 | 取消后继续生产；地址/媒体超期保留 |
| 伙伴/API | B31–B38、B103–B110 | 租户隔离、合同、沙箱、SDK、Webhook、连接器认证 | 未认证伙伴访问生产；Webhook 重放产生副作用 |
| 营销/通知 | B57–B62、B73–B78 | CMS、归因同意、模板、频控、退信/投诉、增量分析 | 同意前追踪；退订后触达；敏感内容出现在锁屏 |
| 客服/CRM/成功 | B79–B86 | 工单、SLA、机器人转人工、受控动作、销售/续约、VOC | 客服越权访问媒体；无审计退款/删除；P0 无升级 |
| 数据/实验 | B111–B118 | Schema registry、仓库、语义层、质量、实验、模型评测 | 仪表板与账本冲突不告警；敏感原文进入分析 |
| 可观测/韧性 | B45–B47、B119–B122 | SLO、容量、DR、混沌、配置/秘密、多区域、回滚 | RPO/RTO 不达标；灰度异常无法暂停/回滚 |
| 软件供应链/合规 | B44、B123–B124 | SBOM、签名、SAST/DAST、渗透、审计证据 | 高危漏洞；制品/证据 commit 不一致 |
| 最终发布 | B125–B127 | readiness、全表面 E2E、release manifest、波次和证书 | 任一关键门失败或证据不可复现 |

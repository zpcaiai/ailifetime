# 完整商业级项目范围

## 1. 产品定义

AI 人生时光机不是单一“变老滤镜”。它是由四个价值层组成的平台：

1. **传播入口**：一张照片和当前年龄，生成 0—100 岁关键帧、年龄变化视频、宫格与分享卡；
2. **情感核心**：家庭关系、共同变老、儿童成长纪念、未来自我故事/信件/目标可视化与安全对话；
3. **交易产品**：数字套餐、订阅、礼品码、照片书、相框、卡片、纪念视频和年度档案；
4. **B2B2C 平台**：影楼、门店终端、纪念礼品、电商、保险养老教育、企业福利、API/SDK/Webhook 和伙伴结算。

## 3. 核心平台能力

- 身份、账户、家庭、伙伴组织、RBAC/ABAC、企业 SSO 与租户隔离；
- 逐人逐用途同意、监护、撤回、导出、删除和下游删除证明；
- 原图/衍生图/视频/音频/向量/分享/供应商副本分层存储与生命周期；
- 图像/视频/LLM/审核/短信/支付/物流/印刷等供应商抽象与路由；
- 持久化工作流、幂等、重试、取消、补偿、死信、重放和人工审批；
- 年龄时间轴、身份一致性、年龄合理性、视频连续性、内容安全、来源证明；
- 商品、价格、套餐、权益、订阅、结账、支付、退款、订单和许可证；
- 通知偏好、模板、本地化、邮件/短信/推送/微信/站内信、旅程与送达率；
- 复式账本、支付/银行/伙伴/供应商对账、发票/税务、收入确认与月结；
- API、OAuth、SDK、Webhook、连接器市场、变更/弃用和伙伴认证；
- OpenTelemetry、SLO、成本、容量、备份、灾备、多区域、混沌、安全与合规证据。

## 5. “完整”的工程含义

本包中的“完整商业级项目”指：上述定义范围均有对应 Skill、Batch、Requirement、契约、测试类型、证据与发布门。它不意味着解压后即可直接上线，也不意味着自动获得法律、税务、会计、安全或行业资质。只有 Claude Code/Codex 在目标仓库完成全部选定批次、真实测试和独立审查后，目标项目才可能获得相应 Profile 证书。

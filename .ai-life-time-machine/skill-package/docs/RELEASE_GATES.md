# Release Gates

| Gate | 主责 Batch | 必需结论 |
|---|---|---|
| G0 仓库基线 | B00、B51 | 真实仓库、Profile、Stack、命令、风险和范围可重放 |
| G1 平台基础 | B01–B05、B12–B13 | 契约、租户、身份、同意、媒体生命周期和持久工作流可运行 |
| G2 AI 媒体 | B07–B18、B118 | 0—100 岁图片/视频在身份、年龄、连续性、安全、来源、延迟和成本上达标 |
| G3 家庭/未来自我 | B19–B24 | 逐人授权、儿童、家庭、未来自我和年度档案安全 E2E |
| G4 核心交易 | B25–B30、B87–B94 | 商品、权益、支付、退款、账本、对账、税票、收入和月结闭环 |
| G5 B2B2C | B31–B38、B84–B85、B103–B110 | 伙伴、影楼、礼品、保险养老教育、CRM、客户成功和集成认证 |
| G6 增长与内容 | B39–B42、B57–B62、B73–B78 | 营销/CMS、分享、通知、实验与归因不破坏隐私和安全 |
| G7 多端体验 | B53–B56、B63–B72 | Web、App、小程序的设计、无障碍、购买、深链和发布一致 |
| G8 客服与供应 | B79–B86、B95–B102 | 工单、受控操作、补救、印刷、物流、退换、索赔和供应商结算 |
| G9 数据经营 | B111–B118 | 事件、数仓、语义层、仪表板、归因、单位经济、实验和模型评测可信 |
| G10 企业信任 | B44–B47、B119–B124 | 安全、SBOM、配置、区域、容量、混沌、DR、删除和合规证据通过 |
| G11 商业准备 | B125 | 团队、政策、合同、商店、供应商、客服、财务和市场上线准备完成 |
| G12 全表面 E2E | B126 | 消费者、家庭、多端、伙伴、支付、实物、客服、财务和删除全链路一致 |
| G13 灰度上线 | B127 | 签名制品、发布波次、护栏、自动暂停、回滚和运营交接通过 |

`full-commercial` 只有在 B00—B127 全部报告通过且 B127 签发最终证书后，才可声明完成。任何关键同意、儿童、安全、租户隔离、账本平衡、删除、数据丢失或回滚失败均不可豁免。

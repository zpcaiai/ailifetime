# KPI 与单位经济目录

## 北极星指标

**每月完成且被本人或获授权家庭成员再次观看/分享/购买的“有意义人生作品”数量。** 该指标同时要求生成成功、授权有效和真实价值，避免只追求低质量图片次数。

## 漏斗

1. 落地页访问 → 合规上传开始率；
2. 上传 → 质量预检通过率；
3. 任务创建 → 首张可用结果时间、完整成功率；
4. 预览 → 付费解锁率；
5. 付费 → 导出/分享/礼赠率；
6. 分享 → 有效新用户与付费归因；
7. 首次作品 → 家庭项目、年度回访和订阅留存；
8. 伙伴线索 → 激活、订单、退款、分账完成。

## 单位经济

按产品、模型、分辨率、重试、视频时长、渠道和租户记录：收入、平台/支付费、推理、存储/带宽、实体制造/物流、退款、客服、伙伴分成与税费。禁止用平均毛利掩盖高成本模板；B18 和 B41 必须形成每次任务贡献毛利与预算熔断。

## 护栏

授权撤回率、投诉率、未成年人事件、内容误用、身份漂移、生成失败、退款/拒付、隐私请求时效、删除完成率、AI标识覆盖率、跨租户负测、未来自我依赖/危机触发、保险渠道用途违规均为一等指标，不得被增长实验覆盖。

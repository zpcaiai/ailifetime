# 产品蓝图

## 核心价值主张

“看见不同年龄的自己”获取注意力；“与家人共同保存时间、与未来自我建立关系”创造情感价值；数字/实物纪念品和年度更新形成交易与复购；影楼、礼品、保险养老教育和开发者生态形成低获客成本的 B2B2C 收入。

## 产品支柱

1. 高身份一致性、连续、可解释质量的 0—100 岁媒体；
2. 逐人同意、儿童保护、私密分享和可验证删除；
3. 家庭关系图、共同变老、年度仪式与未来自我；
4. 数字套餐、订阅、礼品、照片书/相框和售后；
5. 伙伴门户、门店、白标、API/SDK、计量、结算和客户成功；
6. 营销、通知、客服、财务、供应、数据、安全和发布等完整周边系统。

## 非目标

不提供科学容貌预测、寿命/健康预测、保险承保工具、情绪/人格识别、未经授权的陌生人/公众人物深伪，也不通过拟人化未来自我替代真实人际关系或专业帮助。

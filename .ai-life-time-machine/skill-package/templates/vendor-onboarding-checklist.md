# Vendor onboarding checklist
- [ ] Legal entity, contract, region, subprocessor and data-flow review
- [ ] Sandbox credentials and least-privilege production credential process
- [ ] Catalog, price, capacity, SLA, holidays and failure semantics
- [ ] Media access expiry, secure transfer and deletion receipt
- [ ] Synthetic test order, proof, production, tracking, cancellation and claim
- [ ] Reconciliation, invoice, settlement and dispute workflow
- [ ] Security questionnaire, incident contact, continuity and exit plan

# Mobile / mini-program release checklist
- [ ] Signed reproducible build and dependency/SBOM evidence
- [ ] Privacy labels, permissions, account deletion and subscription disclosures
- [ ] AI-generated-content disclosure and reporting controls
- [ ] Sandbox purchase, restore, refund and cross-platform entitlement tests
- [ ] Deep link, push, offline, upgrade and minimum-version behavior
- [ ] Accessibility, performance, crash-free and device matrix results
- [ ] Review notes, screenshots, metadata, staged rollout and rollback/kill switches

# 商业闭环

## B2C

获客内容/分享 → 匿名预览 → 授权上传 → 情感时刻 → 注册/家庭 → 数字或实物购买 → 交付/分享 → 通知/年度更新 → 推荐/复购 → 客服补救。

## B2B2C

伙伴线索 → 合同/配置/品牌 → 沙箱与认证 → 门店/API/SDK 上线 → 消费者授权和交易 → 用量/收入/供应商成本计量 → 伙伴结算/发票 → 客户成功/续约/扩展。

## 经营真相

订单、支付、退款、拒付、权益、伙伴应付、供应商成本、税票和收入确认进入账本与月结；事件仓库用于漏斗、归因、留存、LTV 和实验。任何经营报表与账本冲突时必须调查，而不是把分析层数字当成会计真相。

## 关键护栏

增长不能改变必要告知、安全门、儿童保护、同意或退款权利；推荐和佣金必须披露；保险养老场景只用于教育/反思，不能进入承保、定价、理赔或资格决定。

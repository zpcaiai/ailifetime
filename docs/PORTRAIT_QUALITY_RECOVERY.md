范围：基于 `96c152c706da5b67225753a6a3e73ff85dba6fef` 审查现有生产路径，修复可本地复现的问题。没有调用付费图像服务。以下测试中的人物、分数和 PNG 都是合成的接口边界输入；SQL、授权校验、签名验证、状态变更、HTTP 和文件读写实际执行。

## 实际链路与验收边界

1. B07 接收素材并检查参与者授权；B14 `createTimeline` 生成计划。`packages/capabilities/src/age-generation-plan.ts:47` 的计划为每个年龄保留同一原图锚点、独立种子、年龄指令及九项质量要求；情侣保留两个人的有序参考和逐人目标。提示词本身不能证明身份或年龄效果。
2. `services/workers/src/index.ts:137` 通过配置的 B14 sender 发送真实持久化命令；缺少适配器会报错。通用发送与回调框架存在，但本轮没有配置、运行或认证具体图像供应商。
3. B15 `qualityGate`（`packages/capabilities/src/domains/building-age-media-pipeline.ts:76`）接收有权限服务提交的分数、阈值和模型版本，并绑定原素材、结果图片 ID、SHA256、目标年龄。情侣和换装要求逐人评估。它验证报告，**没有直接分析照片像素或独立证明分数可信**。
4. B17 安全记录与 B15 报告一起由 `packages/capabilities/src/external-business-event-reducers.ts:565` 的 `timelineResultPatch` 在签名回调事务中检查。人物集合、原图、结果摘要、年龄或任何质量/安全维度不匹配，整次 ready 回调被拒绝；不会悄悄发布坏图。
5. `services/api/src/timeline-delivery.ts:36` 汇总 21 个节点和最多三次逐年龄重试。`services/api/src/server.ts:572` 在重试前检查订单付款状态；退款不能重新生成。下载在 `server.ts:580` 再检查可发布状态、文件长度、SHA256 和最新授权。
6. `services/experience-platform/src/media-pipeline.ts` 的 `QualityGateService` 有评估接口、情境阈值和回归停止逻辑，但当前 workers/API/B15 路径未接入它。其单元测试通过不能证明线上质量评分链路已经接通。

## 已修复的问题（P1 本地正确性）

| 问题 | 修复与兼容边界 | 可复现证据 |
| --- | --- | --- |
| B15 接受 0 阈值，发布层要求正阈值，造成已持久化报告无法交付 | 所有阈值必须有限且大于 0、至多 1；分数 0 仍是合法失败分数 | `portrait-quality-contract.test.ts`；HTTP 测试确认拒绝发生在报告落库前 |
| 绑定图片的评分字段可夹带未知维度；部分未达标维度可人工覆盖 pass，但发布层仍拒绝 | 绑定报告严格使用九项维度，换装十一项；任一绑定维度失败均不可覆盖 pass。无图片绑定的历史非关键构图复核行为保留 | 输入 RED→GREEN；原有能力与换装测试保留 |
| 已取消命令被投影为临时失败，CANCELLED 结果也可重试 | 仅 `PROVIDER_TRANSIENT`、`QUALITY_REJECTED` 可重试；取消映射为 `CANCELLED`；策略阻断、复核和待对账均不新建重试 | 实际 SQLite、签名取消回调及命令数量断言 |
| 子任务冻结或成功但缺少结果，节点要求对账而整套状态仍显示 clear | 任一节点待对账即汇总 `reconciliation_required`；原命令不被改写 | 实际 outbox 十次失败进入死信，确认不新建第二次重试 |

原发布层已经拒绝零阈值及不达标报告，本轮没有证据表明存在已上线的质量绕过。正阈值只是输入约束，不能替代阈值校准，也不能保证任意小的正阈值有商业质量。

## 本地覆盖

新增输入契约测试、实际 SQL 恢复测试，以及单人/情侣分别对身份、年龄、逼真度失败的六组 HTTP 场景。每组覆盖：

- 低分报告持久化为 retry；带签名的错误 ready 发布被拒绝；错误图片/年龄绑定及摘要被拒绝。
- 21 个年龄中 20 张已通过的照片保持原样；失败年龄返回 `QUALITY_REJECTED`，没有下载地址，直接下载返回 `404 RESOURCE_NOT_FOUND`。
- 仅补该年龄，重复请求复用原重试；通过的新报告与安全记录使 21 张全部可交付，下载字节及摘要一致；SQLite 重开后仍保留结果。
- 任意一名参与者撤销原图授权后，下载和进一步重试被拒绝。原有订单测试继续验证退款后禁止重试。

执行记录、PID、退出码、原始输出及 SHA256 保存在 `evidence/B15/local-maintenance-evidence.json`。`local-maintenance-traceability.json` 映射 B15-R01～R05；它区分已有本地约束与未实现的生产评估能力。

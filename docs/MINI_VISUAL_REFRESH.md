# 人生时光机 · 小程序视觉更新

本轮统一了全部 10 个页面。暖白纸感底色、深墨蓝主按钮、香槟金刻度与铜棕点缀，配合宋体标题、时光圆环和照片相框，突出“一张照片，走过一生”的体验。没有添加外部人像、示例出图或付费图片资源。

首页突出时光旅程入口；选择照片与年龄编辑页按步骤整理表单；任务页用真实阶段说明进展，不显示虚构进度；相册以照片为中心，保留 21 个年龄节点并突出当前年龄，原图保存、重试与分享各有清晰层级；账户、登录、订单、客服和隐私页使用同一视觉语言。

按钮、输入框在小屏上保留至少 44px 的主要操作高度，选中年龄与未完成状态同时用文字区分。主要配色对比度：正文 10.87:1、辅助文字 4.56:1、铜棕标识 4.53:1、主按钮 11.84:1。隐私页恢复纵向滚动，避免较矮视口无法触达授权操作。

所有 23 个现有 JavaScript 文件与更新前逐字节一致，10 个模板的原有事件处理器集合保留。没有改变登录、同意、支付、照片质量、下载校验或重试规则。

验证使用实际微信开发者工具 Stable 2.01.2510290、基础库 3.7.12：全部 10 页在真实 iPhone 5 模拟器 320px 视口检查页面和主按钮边界；390px 布局初检和恢复原机型后的首页也有截图。原有小程序测试 34/34 通过；真实 SQLite/API/文件系统与模拟器的 10 项时间轴、保存、拒绝处理和恢复检查通过。部分权限拒绝在原生 API 边界注入失败回调，不能代替真实平台授权弹窗。

Zero-Fake 检查器保持未修改；它不扫描 WXML/WXSS/JSON，本轮样式和模板由真实编译、脚本测试及模拟器执行验证。所有源文件回滚前像、执行 PID、日志、截图与 SHA256 位于当前会话的 `mini-visual-refresh` 证据目录。首轮自动化在新布局尚未稳定滚动时点选失败的日志保留，待截图确认触达区域后原点击断言通过，没有替换成直接调用控制器。
